## 2026-03-31 - Vectorizing Technical Indicators in Pandas
**Learning:** Multi-column DataFrame concatenation (`pd.concat(..., axis=1).max(axis=1)`) and Pandas `.iloc` indexing inside loops introduce substantial CPU overhead in technical indicator calculations. Replacing multi-column `pd.concat` with `np.fmax` on 1D NumPy arrays (`.to_numpy()`) yields a ~5.6x speedup for ATR / True Range calculations. Converting Series to 1D NumPy arrays before lookback loops eliminates Pandas `.iloc` indexing overhead, yielding a ~2.6x speedup for crossover detection.
**Action:** Always prefer vectorized 1D NumPy operations (`np.fmax`, `np.diff`, `np.where`) and direct array indexing over multi-column Pandas DataFrame operations or `.iloc` loop lookups when evaluating time-series indicators.
