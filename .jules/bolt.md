## 2026-10-20 - Multi-Column pd.concat and .iloc Indexing in Indicator Loops
**Learning:** In technical indicator calculations evaluated repeatedly across hundreds of market symbols (e.g. ATR, ADX, crossover checks), constructing intermediate multi-column DataFrames via `pd.concat(..., axis=1).max(axis=1)` introduces massive overhead. Replacing `pd.concat` with 1D vectorized NumPy array comparisons (`np.fmax`) speeds up `compute_atr` by ~6.6x. Similarly, replacing `.iloc[i]` access inside loop iterations in `find_recent_cross_up` with direct NumPy 1D array indexing (`.to_numpy()`) yields a ~17x speedup (~158 µs down to ~9 µs per call).
**Action:** Always convert Series to NumPy arrays (`.to_numpy()`) prior to loop iterations and use 1D array vectorized operations instead of multi-column `pd.concat` for True Range computations in hot path indicators.
