## 2026-03-30 - Vectorize True Range and avoid Series indexing in indicator calculations
**Learning:** In Pandas, multi-column `pd.concat([..., ...], axis=1).max(axis=1)` creates significant DataFrame overhead for calculating True Range across rows. Converting series to NumPy arrays via `.to_numpy()` and using `np.fmax` with shifted lag array reduces execution time by ~23x for True Range calculation and ~1.75x across technical indicators (`compute_atr`, `compute_adx`). Additionally, converting `pd.Series` to NumPy 1D arrays prior to lookback loops in crossover checks avoids `pd.Series.iloc` indexing overhead.
**Action:** Replace `pd.concat(..., axis=1).max(axis=1)` with NumPy `np.fmax` on `.to_numpy()` arrays, and convert `pd.Series` to NumPy arrays before indexing in tight loops.
